# Dawit Data

Lead management + bilingual landing page for a data entry & analysis freelance business.

**App code:** see [`dawit-data/`](./dawit-data/)

```bash
cd dawit-data
cp .env.example .env   # set a strong ADMIN_TOKEN
npm install
npm start
```

- Landing: http://localhost:3000  
- Admin: http://localhost:3000/admin
